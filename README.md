# Mywyau Tap

## How do I install these formulae?

`brew install mywyau/tap/<formula>`

Or `brew tap mywyau/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "mywyau/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
